How It Works

5-Factor Scoring Algorithm

  1. Practice Performance — ML analysis of FP sessions
  2. Qualifying Speed — Raw pace + grid position trends
  3. Race Pace — Consistency over multiple laps
  4. Value — Points-per-million analysis
  5. Track Match — Historical performance at circuit
